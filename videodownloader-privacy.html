Политика конфиденциальности VideoDownloader

Последнее обновление: 30 сентября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные собирает приложение VideoDownloader («Приложение») и как они используются.

2. Какие данные мы собираем

Приложение НЕ собирает и НЕ передаёт третьим лицам:

  • Ваше имя, email, номер телефона
  • Историю ваших загрузок
  • Ссылки, которые вы вставляете
  • Скачанные файлы
  • Данные о местоположении
  • Контакты, фото, сообщения

3. Какие данные передаются наружу

При скачивании видео Приложение отправляет ТОЛЬКО ссылку на видео (например, "https://tiktok.com/...") на сервер-посредник для получения прямой ссылки на файл. Эта информация не сохраняется на сервере и не связывается с вашей личностью.

Серверы-посредники:

  • tikwm.com — для TikTok
  • Публичные инстансы Cobalt — для Facebook

4. Разрешения приложения

Приложение запрашивает следующие разрешения:

  • INTERNET — для скачивания видео
  • READ_MEDIA_VIDEO, READ_MEDIA_IMAGES, READ_MEDIA_AUDIO — для отображения скачанных файлов в галерее приложения
  • POST_NOTIFICATIONS — для показа прогресса загрузки
  • WAKE_LOCK — чтобы загрузка продолжалась при выключенном экране

Все разрешения используются исключительно для работы функций приложения.

5. Хранение данных

Все скачанные файлы хранятся ТОЛЬКО на вашем устройстве в папке DCIM/VideoDownloader/. История загрузок хранится в локальной базе данных Room и удаляется вместе с приложением.

6. Cookies

Приложение НЕ использует cookies и не отслеживает пользователей.

7. Дети

Приложение не предназначено для детей младше 12 лет. Мы не собираем данные о детях.

8. Изменения в политике

Мы можем обновлять эту политику. Актуальная версия всегда доступна по этому адресу.
